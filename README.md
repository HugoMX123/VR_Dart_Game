# VR Dart Game

A simple VR dart game made in Unity using Leap Motion hand tracking.

## About

This project uses Leap Motion to track the player's hands and allow natural interaction in VR.

Players can grab and throw darts using real hand movements instead of traditional controllers.

## Technologies Used

* Unity
* C#
* Leap Motion / Ultraleap SDK
* VR/XR Toolkit

## Features

* Hand tracking with Leap Motion
* Physics-based dart throwing
* VR interaction system

## Game Modes

### Practice Mode
Throw darts freely and track your score while practicing alone.

### AI Mode
Play against an AI opponent who makes random dart throws.

## Prerequisites

Make sure you have the following installed:

- [Unity](https://unity.com/) (version used in this project: `2022.3.19f1` or above)
- [TextMeshPro](https://assetstore.unity.com/packages/essentials/beta-projects/textmesh-pro-84126) (for UI text)
- [Pirate Tavern from Unity Asset Store] (https://assetstore.unity.com/packages/3d/environments/fantasy/pirate-tavern-113463)
